# Wine Quality & Type Prediction

## Objective
Build ML models to predict wine quality and wine type.

## Models Used
- Linear Regression → predict wine quality
- Logistic Regression → classify red vs white wine

## Results

### Linear Regression
- MAE: 0.56
- MSE: 0.54
- R²: 0.27

### Logistic Regression
- Accuracy: 98.77%
- Precision: 99.06%
- Recall: 99.27%
- F1 Score: 99.17%
